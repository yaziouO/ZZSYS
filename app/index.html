RELEASE NOTES
更新公告4.46
4.46本次
新增Webp转GIF：WebP 动图逐帧转 GIF，可调颜色数、帧率、尺寸，支持透明帧。
修复MP4修剪工具不能拖入视频，现在拖进去即识别；安卓端作战图生成成品偶发 E001 报错，已加备用导出通道，失败时提示第几张图。
4.45
新增GIF 缩减工具：动图/静态图都能压小，缩完先看体积再保存；多选拖拽粘贴都行；GIF 可缩尺寸、减色、降帧，静态图四档画质；顺带清掉图里藏的附加数据、注释、EXIF，写明清掉多少。
修复成品总有一张取不出（载体自带注释块）：生成时剥旧注释、取图按工具标记认块，旧成品免重生成；旧成品当载体残留旧数据会撑爆分段，生成前先剥净；分段预算按每张载体各算并计入音频，超上限缩载体重做，放不下提示该调到多少 MB。
4.44
新增GIF 表图随视频一起分段（可勾选，默认开）；动图过大时自动缩分辨率；表图是动图时成品格式自动切 GIF。
修复动图分段预算计算异常导致成品张数不对。
4.40
新增图种载体图多选轮转、分段成品单张「换表图」；成品 PNG 无损直通 / GIF 保动画；取图内存直取；更新弹窗改暗色卡片。
修复分段成品「保存全部」没反应；非图片文件提示含糊；版本号与安装包不一致。
4.39
新增载体图逐张追加与单独移除，多张按段轮换；错误码扩到 143 条，页面底部显示运行环境。
修复「保存全部」同名 id 冲突；页面角标与安装包不一致。
4.38
新增光棱图没生成就点保存或显形测试，改为直接报错误码，不再默默存空白画布。
修复光棱图未生成时存空白画布；清理 8 处无调用死代码。
4.35
修复取图页与折叠行的问号位置错位，不再飘到按钮区、不再压住折叠行；App 多选多张成品时每张都能原生直读，不再只读第一张。
4.33
新增「TS 转 MP4」独立工具：只换容器不转码，支持图种/分卷剥出的 .ts，分卷合成的也能一键转。
网页版刷新即可生效；APP 覆盖安装不丢原有图片与设置。更早的版本说明见 GitHub 提交记录。
